# Curso Meta Ads — Ads.Not.Dead

Landing page del curso de Meta Ads.

## Deploy

Conecta este repo en [vercel.com](https://vercel.com) y se despliega automáticamente. No requiere configuración adicional — es un sitio estático puro.

## Editar contenido

Todo el contenido y el estilo están en `index.html`. Busca estos bloques para editar rápido:

- **WhatsApp:** reemplaza `56900000000` con tu número real (formato: código de país sin `+`)
- **Número de clases / horas:** sección `<!-- FORMAT -->`
- **Módulos:** sección `<!-- CURRICULUM -->`
- **CTA final:** sección `<!-- FINAL CTA -->`
